Myanmar Font Reshaper for PDF

Fix Myanmar Unicode rendering in Odoo PDF Reports

Fixes Myanmar Unicode character ordering and rendering issues in Odoo 19.0 QWeb PDF reports.

Features

  • Myanmar Unicode character reshaping
  • Fixes broken Myanmar letters in PDF reports
  • Supports KinZi, medial characters and subjoined consonants
  • Improves Myanmar font rendering in QWeb reports

External Dependency

Requires BeautifulSoup4 (bs4). 

pip install beautifulsoup4
